# Fake Influencer Detection System

A machine learning and SQL-based analytics project that detects fake influencers using engagement metrics, follower patterns, and suspicious activity analysis.

## Features
- Detect fake influencers
- Analyze engagement rate
- Follower vs likes comparison
- Suspicious account identification
- Data visualization support

## Technologies Used
- Python
- SQL
- Pandas
- Scikit-learn
- Streamlit

## Machine Learning Model
- Random Forest Classifier

## Project Structure
- app.py → main application
- dataset.csv → influencer dataset
- queries.sql → SQL analysis queries
- model training and prediction logic included

## Future Improvements
- Real-time Instagram API integration
- Advanced fake engagement detection
- Dashboard analytics
